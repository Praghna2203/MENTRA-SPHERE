🧠 Mentra Sphere
Beyond Symptoms. Matching for Connection. The First AI-Orchestrated Coordination System for High-Retention Group Therapy.

🚀 The Core Innovation
Traditional group therapy fails because of poor matching. Mentra Sphere replaces random assignment with Resonance-Based Clustering.

Our AI doesn't just match clinical diagnoses (e.g., Anxiety); it creates Micro-Communities based on shared Coping Mechanisms (e.g., Gaming, Art, Nature). We group users who share both a struggle and a passion, ensuring immediate social cohesion. *
✨ Key Features
🌿 Empathetic AI Intake: A conversational agent that replaces rigid medical forms, extracting clinical variables through natural dialogue.

🔗 Resonance Engine: Clusters users by Clinical Need + Shared Interest, creating groups like "The Creative Founders' Circle" instead of "Anxiety Group B."

📄 Zero-Touch Handoff: Auto-generates a Therapist Dossier (PDF) with group insights and icebreakers before the session starts.

🛡️ Privacy-First: Ephemeral data processing ensures sensitive chat logs are categorized but never permanently stored in the orchestration layer.

🛠️ Tech Stack
Frontend: Streamlit (Python) for a seamless, calming UI.

Logic: Semantic Keyword & Sentiment Analysis (NLP).
Orchestration: Pandas-based Multi-Vector Clustering.
